## 1. 改动

| 位置 | 内容 |
|---|---|
| `rtl_custom/lat_probe.v`（新） | `us_gray_counter`：50 MHz 晶振的微秒计数，格雷码输出。<br>`gray_sync`：两级同步后转二进制。<br>`ts_stamp`：在摄像头时钟域，把时间和摄像头帧号写进每帧第一个帧缓存字，即第 0 行的像素 0..4。<br>`lat_meter`：在 HDMI 像素时钟域读回这几个像素，计算延迟（µs）和其间的摄像头帧数。每 8 帧刷新一次显示值，另取 64 帧窗口内的最大值 |
| `rtl_custom/motion_det.v`（新） | 画面分成 32×18 个 40×40 像素的单元。每个单元用 10×10 个采样点估计平均亮度 Y=(R+2G+B)/4，存成 8 位：cur = 采样和 >> 7。与上一帧同一单元相比，\|cur−prev\| ≥ 6 就算该单元在动。<br>上一帧数值存 1 块 ERAM（576×8）。运动图 32×32 位，同步读口给叠加层用。<br>每帧输出运动单元数和外接框 |

| `rtl_custom/contest_vision_v2.v` | 新增参数 `LOGO_EN`（默认 1，旧工程行为不变）；adv 工程设为 0，Logo 由 top_osd 统一画 |
| `rtl_custom/yolo_top.v` | 新增参数 `N_MODES`（默认 5）；adv 工程为 6：KEY3+KEY4 依次切换 CV → YOLO → CV+YOLO → CAPTURE → WB → **MOTION** → CV |
| `design_top_wrapper.v`（adv） | ① isp_top 与 video_in 之间插入 ts_stamp。<br>② 帧缓存读出流接 video_pos_adapter，再分给 lat_meter 和 motion_det。<br>③ wb_osd 后接 top_osd，再进 hdmi_tx。<br>④ 运动页用原图作底（与 YOLO 页、WB 页相同），yolo_osd 的状态行在运动页关闭。<br>⑤ **删掉平场诊断（shade_diag）、HDMI 测试图案、诊断数码管**，腾出面积。SW1..SW3 全下现在就是普通原图视图；诊断功能仍在 isp04 / wb02 位流里，需要重新测量时用它们 |

跨时钟路径：sys_clk_50m → MIPI 字节时钟，是 SDC 里的异步时钟组；sys_clk_50m → HDMI 像素时钟有 set_false_path；MIPI → HDMI 也是异步时钟组。都用格雷码加两级同步，SDC 不用改。

延迟的含义：从 ISP 输出这一帧的第一个字，到 HDMI 读出这一帧第一个像素的时间，即帧缓存加 FIFO 的延迟。不包括传感器曝光/读出，也不包括显示器自身的处理时间。精度约 1 µs。

## 7. adv02（2026-10-27）：Y 坐标修复 + 直方图均衡页

### 7.1 Y 坐标常为 0000（进阶 2）

- 现象：串口和 CV 面板长时间报 `R:OVAL/OBJ, X0639..0641, Y0000, A≈1850..1950`，画面中没有红色物体时也报“TARGET:FOUND”。真实物体出现时，Y 变成 225、315 之类的值。
- 分析：frame_bbox 的中心 cy = (ymin+ymax)/2。cy = 0 说明命中像素只在第 0..1 行。X≈640、面积≈1.5×1280，说明这两行整行都被判成了红色。所以帧缓存读出的最上面一两行有一条偏色伪像，推测是去马赛克在图像上边界缺少上一行数据造成的。真实物体出现时，它的 ymin 也被这条伪像拉到 0，于是 cy 等于物体底边的一半，跟踪框的上沿也跟着错。
- 修复：`contest_vision_v2` 新增参数 `BORDER`（默认 0，旧工程行为不变；adv 工程设为 4）。距画面边缘不足 4 像素的命中，在 frame_bbox 和掩膜视图之前丢掉。
- 验证：ModelSim `tb_vision_v2` 回归（默认参数）见 STATUS。上板效果待验证：画面中没有目标时，面板应显示未找到；有目标时 Y 应为它的真实中心。

### 7.2 直方图均衡页（进阶 5）

- `rtl_custom/he_eq.v`，第 7 个页面 HIST EQ（KEY3+KEY4 循环：CV → YOLO → CV+YOLO → CAPTURE → WB → MOTION → HIST EQ）。
- 统计：帧缓存读出流中 x、y 都为偶数的像素（每帧 230400 个），亮度 Y=(R+2G+B)/4，累加到 256 级、18 位的直方图。
- 生成映射：每帧最后一个像素之后，在场消隐期按 256 级逐级算出 CDF，再得到 lut = min(255, (CDF×74274 + 2^25) >> 26)，同时把直方图清零。
- 应用：每个通道 c' = clamp(c + lut[Y] − Y)，即把亮度均衡，颜色差保持不变。
- 显示：左下角 (16,600) 处 256×100 的图，灰色柱是上一帧直方图（每单位 32 个计数，最高 99），黄线是映射曲线。top_osd 右上角第三行显示 `HIST EQ`。
- 存储全用 LUT 分布式 RAM（直方图 256×18、映射 256×8 带两个读口、柱高 256×7），不占 ERAM（ERAM 只剩 1 块）。
- 直方图 RAM 没有复位：复位后的第一次生成只用来清零，从第二次开始才使用映射。
- 仿真：`tb_custom/tb_he_eq.v` 共 5 帧，逐像素与测试台里的模型比较，包括图形区，结果 **PASS**。变异测试见 STATUS。

- 2026-10-27 用户实物确认（adv02，SRAM）：Y 坐标正常；HIST EQ 页可用。
