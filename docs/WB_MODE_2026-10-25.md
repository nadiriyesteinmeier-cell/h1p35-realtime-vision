# 白平衡调节模式（WB 页）2026-10-25（Claude）

> 状态：RTL、单元仿真、变异测试、系统级仿真、TD 完整构建均已完成；**尚未上板**（开发板 USB-JTAG 当前未被 Windows 检测到）。不要把下面的仿真/构建结果当成实物通过。

## 1. 怎么用

KEY3+KEY4 同时按（和弦）切换页面：`CV` → `YOLO` → `CV+YOLO` → `CAPTURE` → **`WB`** → `CV`。诊断视图（SW1–SW3 全下）里和弦无效，WB 页也不会出现。

WB 页上的按键（这一页里传统检测 contest_vision_v2 收不到按键）：

| 按键 | 作用 |
|---|---|
| KEY1 | 选中的增益 −0.01；按住 0.5 s 后连续减（每秒 16 次），按住 2 s 后每次 −0.05 |
| KEY2 | 选中的增益 +0.01，连发同上 |
| KEY3 单按 | 选中 R → G → B → R（松开时生效；按住期间 KEY4 被按过则不算） |
| KEY4 单按 | 模式 AUTO → MAN → OFF → AUTO（松开时生效）。**从 AUTO 进 MAN 时接管 ISP 当前的自动增益**（一键白平衡：对着白纸/灰卡在 AUTO 下按 KEY4） |
| KEY4 按住 1 s | MAN，R/G/B 全部回到 1.00 |
| KEY3+KEY4 | 下一页（回到 CV） |

在 AUTO 或 OFF 下直接按 KEY1/KEY2，会先切到 MAN（从当前实际增益开始），再走一步，画面不会跳。离开 WB 页后，模式和增益**继续生效**，所以可以先在 WB 页调好，再回到 CV/YOLO 页工作。手动范围 0.25–4.00（步进 0.01）。

画面（1280×720）：

- 中央 128×128 测量窗（x 576–703，y 296–423），外面画 2 像素黄框；
- 左下三行字：
  - y=688 `WB AUTO R1.32 G1.00 B0.87`：模式与 **ISP 实际正在用的增益**（从 ISP 读回，不是按键里存的值），选中的那一项黑字黄底；
  - y=668 `AVG R128 G130 B127`：测量窗的 R/G/B 平均值（0–255，上一帧的）。对白纸/灰卡调到三数相等即中性；
  - y=648 `K1- K2+ K3 SEL K4 MODE K3+K4 NEXT`。
- WB 页显示的是**ISP 原始输出**：三级 camera_tone（color4 校色、提亮、饱和度）在这一页关闭，也不叠加传统检测的框/十字/文字，所以测量窗读数就是 YOLO 输入看到的颜色。

## 2. 实现

| 文件 | 内容 |
|---|---|
| `rtl_custom/awb_frame.v`（改） | `I_mode` 0 AUTO（原灰度世界）/ 1 OFF（单位增益）/ 2、3 MAN（`I_man_r/g/b`，Q4.12）。**所有模式和增益只在一帧的第一个节拍切换**（原来 OFF 是立即生效）。新增 G 通道增益：G 的 4 个乘法用两个 4 位半积的移位相加（第一级）+ 求和饱和（第二级），**不占 DSP**（DSP 仍 36/40）；延迟不变（DELAY+2）。新增读回 `O_gain_r/g/b` = 当前帧实际增益。 |
| `rtl_custom/wb_ctrl.v`（新） | HDMI 像素时钟域。4 个按键去抖、加减连发、KEY3/KEY4 单按（松开时、无和弦、按下到动作期间页面一直在）、KEY4 长按复位；模式/选择/手动增益（百分数 h，25–400）；h → Q4.12：`((h*41)*1023+512)>>10` = round(h·4096/100)，h≤400 时精确；读回 Q4.12 → 百分数 `(g*25+512)>>10`；6 个显示值顺序做 BCD（约 20 拍/个，循环刷新）。 |
| `rtl_custom/wb_osd.v`（新） | 叠加（3 拍延迟，与 yolo_osd 同结构，字库只含用到的字符，新增 `.` `-`）；测量窗统计（在**输入流**上，16384 像素和 >>14，完整一帧才更新）；模式/选择/数字在 vs 边沿锁存，一帧内不变；文字列用递增计数器（不做逐像素比较）。 |
| `rtl_custom/yolo_top.v`（改） | 模式 3 位，0–4 循环，模式 4 = WB 页（网络照常运行，UART 交还传统检测）。默认参数改为实测 PLL 频率 75.0 MHz：`MS_DIV` 75000（原 74250，延迟显示原来偏大约 1%）、UART `CLKDIV` 651（原 645，波特率原来偏 +0.9%）。 |
| 工程 `contest_work_v3_wb`（新，yolo 工程完整复制） | `isp/isp_top.v`：手动增益输入、实际增益输出。`design_top_wrapper.v`：送 ISP 的 AWB 模式 = 诊断视图时用 shade_diag 的，否则用 wb_ctrl 的（仍是两级同步）；手动增益 48 位用 `byte_cdc`（两级 + 连续两次相等才更新）送进摄像头时钟域，实际增益同样方法送回像素时钟域；WB 页时关闭三级 camera_tone、contest_vision 按键屏蔽、显示基础流；`wb_osd` 串在 `yolo_osd` 后面、`hdmi_tx` 前面；yolo_osd 状态行在 WB 页隐藏。 |

时钟与延迟：摄像头时钟 MIPI_RX_BYTE_CLK（60 MHz）与 HDMI 像素时钟（75.0 MHz）在 SDC 里是异步组，两条 CDC 都只传慢变量（每次按键最多变一次 / 每帧最多变一次）。按键 → 手动增益寄存器 2 拍 → CDC 约 3 拍 → **下一摄像头帧开头生效**（最多约 1 帧）→ 帧缓存 → 显示；屏幕上的增益数字是读回值，再晚约 1 帧；窗平均是上一帧的。

诊断视图（SW1–SW3 全下）保持原样：KEY1 在那里切换 AWB 0/1，ISP 用诊断块的模式；离开诊断视图回到 WB 页设置。

## 5. 上板检查（需要用户操作和看屏幕）

1. 连上 USB、上电后，在终端下载（只写 SRAM，不写 Flash）：
   `powershell -ExecutionPolicy Bypass -File F:\fpga_s2\tools\board\program_sram.ps1 -Bit F:\fpga_s2\release\contest_work_v3_20261025_wb02.bit`
   脚本会先核对 release 目录与 SHA256、检测 USB-JTAG（VID_0403 PID_6042），再执行 BitWriter 界面同款命令 `download -bit … -mode jtag -spd 7 -cable 0`，日志在 `logs_custom/bw_cli/`。
2. W1：上电默认 CV 页，画面与 yolo01 相同（回归）。和弦 4 次进 WB 页：出现黄框和三行字，左下 `WB AUTO`，增益数字非 0。
3. W2：对白纸/灰卡（填满黄框），记录 AUTO 下三行读数和照片；按 KEY4 → `WB MAN`，增益数字不变、画面不跳。
4. W3：KEY3 选 R，KEY2/KEY1 各按几次，R 数字按 0.01 变、画面偏红/偏青；按住看连发与加速。调到 `AVG` 三数相等，拍照。
5. W4：再按 KEY4 → `WB OFF`，增益显示 1.00/1.00/1.00（无白平衡的原始色），拍照对比；再按 KEY4 回 AUTO。
6. W5：在 MAN 下和弦回 CV/YOLO 页，确认调好的白平衡继续生效；再回 WB 页，设置还在。KEY4 按住 1 s → 三个 1.00。
7. W6：SW1–SW3 全下进诊断视图，KEY1 切 AWB 0/1 仍按原诊断文档工作；回到正常视图后 WB 设置恢复。

需要回传：每步屏幕照片（尤其三行读数）、是否有闪烁/撕裂/花屏、按键是否误触发。

## 6. 已知限制 / 未做

- **未上板**；所有结论来自仿真和 TD。
- YOLO 页（1）和 WB 页（4）显示的是基础流，没有 contest_vision 的 OSD，因此**这两页没有安路 Logo**（yolo01 的 YOLO 页本来就这样）。赛题要求 OSD 含 Logo，演示时应在 CV/CV+YOLO 页展示 Logo；以后若要每页都有 Logo，需要让 contest_vision 输出“只有 Logo 的叠加”或共享 Logo ROM（ERAM 只剩 2 块，不能再放一份）。
- 手动白平衡只作用于 ISP；CV 页里 color4 的静态校色（R×1.25 等）仍会叠加在后面。如果用 WB 页调好了，可能需要关掉 color4 静态校色（目前由拨码决定），这要看实物效果再定。
- Slice 93%：后续再加大模块前，先回收面积（例如 key_debounce 32 位计数器、共享去抖、CDC 改传百分数）。
- 测量窗固定在画面中心 128×128，未做可移动。
- 回退位流：yolo01（`contest_work_v3_20261024_yolo01.bit`）、isplite01、color4 均保留。
