## 1. 拍摄前准备（约 20 分钟）

### 1.1 网络与供电：做到“全程不用电脑”

| 设备 | 演示时的接法 |
|---|---|
| FPGA 开发板 | 只插电源适配器；**拔掉连电脑的 USB-C**（它只用于开发调试） |
| ESP32 | Micro-USB 插**手机充电头或充电宝**，不插电脑；FPGA J1 的两根线保持不变 |
| Wi-Fi | **推荐用手机热点**（2.4 GHz），瓦力和 ESP32 都连这个热点；电脑可以关掉、移出画面 |
| 瓦力 | 充好电，放在桌上，**用手势规则**（不移动） |

改连手机热点的步骤：
1. 瓦力用它自己的配网方式连上手机热点。
2. ESP32：按住 BOOT 3 秒 → 板载蓝灯快闪 → 另一部手机连 Wi-Fi “WALLE-BRIDGE”，**关掉移动数据** → 浏览器打开 `http://192.168.4.1` → 填手机热点的名称和密码 → 保存并重启。
3. 等 OLED 第一行出现 `ROBOT OK`，就表示连上了。

时间不够的话，也可以继续用电脑热点。但电脑**不要入镜**，字幕写“电脑仅作 Wi-Fi 热点，不运行程序”。

### 1.2 桌面布置

一个镜头里要能同时拍到这几样：
- **显示器**放在中间；
- **开发板**放在显示器左前方，按键、拨码、数码管朝向镜头；
- **ESP32 + OLED + 三色灯**放在显示器底座前，OLED 竖起来朝向镜头；
- **瓦力**放在显示器右侧，面朝镜头；
- 摄像头用胶带固定好，镜头朝上。拍摄时移动的是物体，**不要扳摄像头**。

### 1.3 清场（防止出现学校信息）

- 撤掉印有学校名称的**鼠标垫**、**布袋**、校徽、校服、带校名的本子和纸张。
- 电脑壁纸、浏览器标签页都不能入镜。热点名称和密码也不能入镜。

### 1.4 道具

- 红色收纳盒、绿色铁框、蓝色泡沫块（三个识别目标）；
- 一张白纸（白平衡用）；
- 一块深色布或纸（直方图均衡时遮暗用）。

### 1.5 开拍前板子的状态

- 先**断电**；
- 拨码：**SW1 上、SW2 下、SW3 下、SW4 上、SW5 下（开蜂鸣器）、SW6 上（数码管）**；
- ESP32 和瓦力提前开好，OLED 显示 `ROBOT OK`。

### 1.6 人员分工（2 人）

| 角色 | 负责 |
|---|---|
| 甲：摄像 | 手机横屏 1080p，**锁定曝光和对焦**（长按屏幕），有稳定器就用；推近和拉远按脚本来 |
| 乙：操作 + 道具 | 摄像头就装在开发板上：**左手在镜头上方拿物体，右手拨开关、按按键**。物体要**举近一些**，面积够大才会触发瓦力 |

- 需要两只手同时按的只有 KEY3+KEY4（切页）。切页时手里不要拿物体：先放下物体再切。
- 另一种拍法：手机用支架固定在全景机位，开 **4K** 录制，后期从 4K 画面裁出特写，当作“推近”。这样两个人都能腾出手来操作。

## 2. 实拍分镜（“视频展示”段，约 2:30；时间为成片时间，片头之后开始）

| 成片时间 | 速度 | 画面 / 操作 | 镜头 | 字幕 |

各段可以分开拍，剪辑时按上面的顺序接起来；每段内部保持连续，不要从中间剪掉操作过程。

拍摄中途出错（物体没识别、瓦力没反应）时，可以重拍这一段，或者剪掉失败的片段；不要剪掉正常的操作过程。
