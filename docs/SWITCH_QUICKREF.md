更新：2026-10-29（Claude）。适用于 `release/contest_work_v3_20261028_advy03.bit`，即 2026-10-28 写入 Flash、冷启动验证通过的版本。

依据代码：`contest_work_v3_advy/user_source/hdl_source/design_top_wrapper.v`（camera_tone 使能条件、页面选择）、`custom/contest_vision_v2.v`（开头的注释与开关同步逻辑）、`custom/yolo_top.v`、`custom/wb_ctrl.v`。

旧版速查表（10-08，color4）存放在 `handoff/archive/SWITCH_QUICKREF_2026-10-08_color4.md`，与当前版本的区别：
- SW1 拨下时 SW4 的“校色”和“纯灰诊断图”已删除；
- 静态校色已由片上 ISP 取代。

“上”和“下”指拨码开关的物理方向；代码里上 = 1。

## 1. 页面（KEY3 + KEY4 同时按下再松开，依次切换）

CV → YOLO → CV+YOLO → CAPTURE → WB → MOTION → HIST EQ → CV。

上电后在 CV 页。每个页面左上角都有安路 Logo，右上角都有延迟读数 `LAT xx.xMS nF / MAX`。

| 页面 | 画面 | 串口（J1 → ESP32） | 瓦力 |
|---|---|---|---|
| CV | 传统识别（受 SW1–SW4 控制） | 传统识别报告 | 会动 |
| YOLO | 原图 + YOLO 框（类别字母 + 置信度） | YOLO 报告 | 会动（YOLO 驱动，无越线事件） |
| CV+YOLO | 传统识别画面 + YOLO 框 | YOLO 报告 | 会动（YOLO 驱动） |
| CAPTURE | 传统识别画面；串口导出训练图像 | 图像数据 | 不会 |
| WB | 白平衡页（中央测量窗 + 3 行文字） | 传统识别报告 | 会动 |
| MOTION | 运动格染红 + 黄色外接框 + MOTION 计数 | 传统识别报告 | 会动 |
| HIST EQ | 直方图均衡画面 + 左下角直方图与映射曲线 | 传统识别报告 | 会动 |

## 2. SW1–SW4

### 2.1 CV、CV+YOLO、CAPTURE 页

**SW1 = 上：处理画面**
- 自动加亮度提升和饱和度 ×1.25。
- SW2/SW3 选择视图，分两组，KEY2 按住约 1–2 秒后松开，在两组之间切换。
- SW4 控制计数线与目标框的显示。

| SW2 | SW3 | 分析组（上电默认） | 风格组 |
|---|---|---|---|
| 下 | 下 | ORIG 原图 | SKETCH 素描 |
| 上 | 下 | GRAY 灰度 | CARTOON 卡通（8 级色阶 + 黑边） |
| 下 | 上 | MASK 二值化掩膜（黑底，只显示检出的红绿蓝区域） | EDGE+（Sobel 边缘叠加在调暗的画面上） |
| 上 | 上 | TINT 在原图上给目标着色 | THERMAL 亮度伪彩色（不是测温） |

- SW4 上：显示计数线和目标框 / 十字。KEY1 打开三色面板后显示红、绿、蓝三个框。
- SW4 下：隐藏计数线和框。计数、识别、串口都照常进行。

**SW1 = 下：原图（基线画面）**
- 不显示识别面板、框和计数线，后台识别与串口照常，瓦力照样会动。
- SW2 = 上：饱和度 ×1.25。
- SW3 = 上：轻度提亮。
- SW2 和 SW3 都下：ISP 输出的原样画面。
- SW4 不起作用。

### 2.2 YOLO、MOTION、HIST EQ 页

这几页的底图是原图，SW2/SW3 不再选择视图，SW4 不起作用。
- 提亮：SW1 或 SW3 拨上时开启。
- 饱和度 ×1.25：SW1 或 SW2 拨上时开启。

演示时保持 SW1 上，各页观感一致。

### 2.3 WB 页

提亮和饱和度都强制关闭（看的是 ISP 实际输出），SW1–SW4 不起作用。

## 3. KEY1–KEY4

### 3.1 CV、YOLO、CV+YOLO、CAPTURE、MOTION、HIST EQ 页（传统识别始终在后台运行）

| 操作 | 功能 |
|---|---|
| KEY1 短按 | 三色识别面板开 / 关（颜色、形状、坐标、越线计数、跟踪状态 HOLD / LOST） |
| KEY2 短按 | 固定阈值 FIXED ↔ 自适应阈值 ADAPT（实测 ADAPT 误检更少） |
| KEY2 按住约 1–2 秒后松开 | 分析组 ↔ 风格组 |
| KEY1 + KEY2 同时短按 | 清零越线计数和跟踪统计 |
| KEY3 / KEY4 单按 | 计数线左 / 右移 16 像素，按住连续移动 |
| KEY3 + KEY4 同时按下再松开 | 切换到下一页 |

上电 / 复位后：分析组、FIXED、面板关闭、计数线居中。

### 3.2 WB 页（按键只给白平衡用）

| 操作 | 功能 |
|---|---|
| KEY4 单按 | AUTO → MAN → OFF → AUTO。AUTO 时对准白纸按 KEY4，就是一键白平衡：进入 MAN 并接管当前增益 |
| KEY3 单按 | 选择通道 R → G → B |
| KEY1 / KEY2 | 选中通道 −0.01 / +0.01；按住连续调，2 s 后每步 0.05 |
| KEY4 按住 1 s | MAN 模式，三路复位为 1.00 |
| KEY3 + KEY4 | 切到下一页 |

## 4. SW5、SW6（板上硬件开关，不经过 FPGA）

| 开关 | 功能 |
|---|---|
| SW5 下 | 接通蜂鸣器：每次越线响一声 |
| SW5 上 | 蜂鸣器静音 |
| SW6 上 | 八位数码管：左四位为越线总数，右边 `F` + 摄像头帧率（如 F060） |
| SW6 下 | 与数码管共用引脚的双色 LED（会乱闪，属正常） |

4 个用户 LED 分别表示（代码中 led[0..3]，与板上 LED 编号的对应关系未逐个核实）：
- 发现目标；
- 几何错误（应常灭）；
- 心跳（闪烁）；
- 处理画面开启（SW1 上）。

## 5. 演示推荐设置

1. 上电，停在 CV 页。设置 SW1 上、SW2 下、SW3 下、SW4 上（ORIG + 计数线与框），SW6 上（看数码管）。现场嘈杂或需要安静时 SW5 上。
2. KEY1 打开三色面板，KEY2 短按切到 ADAPT。拿红、绿、蓝物体演示识别、形状、坐标、跟踪与越线计数；瓦力同步做动作。
3. 依次拨 SW2/SW3，展示灰度、二值化掩膜、着色。KEY2 长按切到风格组，展示素描、卡通、边缘、伪彩色，再长按回到分析组。
4. SW1 拨下，展示未加叠加的原图；SW2/SW3 可加饱和度或提亮做对比。之后拨回 SW1 上。
5. KEY3+KEY4 进入 YOLO 页：神经网络框 + 置信度，瓦力由 YOLO 驱动。再按一次进入 CV+YOLO，对比两种识别。
6. 再按：
   - CAPTURE：说明这是板上数据采集，用于训练，这一页瓦力不动，可以快速跳过；
   - WB：按 KEY4 展示 AUTO / MAN / OFF 和一键白平衡；
   - MOTION：在镜头前挥手，看运动格和计数；
   - HIST EQ：遮暗画面，看均衡效果和左下角直方图；
   - 最后回到 CV。
7. 全程指给评委看右上角的延迟读数。
